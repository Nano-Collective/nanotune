Fixes from a full run of the release smoke test on Apple Silicon. Installing PyTorch or `mlx-lm` inside a virtualenv no longer fails with "Can not perform a '--user' install", which broke the venv remedy that the externally-managed-environment error recommends. The exit hint on `export`, `benchmark`, `benchmark compare`, `benchmark review`, `judge test`, `status` and `data validate` now names the keys that really exit (Enter, Esc, and `q` where it applies) instead of "Press any key". `benchmark review` offers the latest run of your model instead of a newer `--base` control, and `benchmark compare` with no or one argument always treats a `--base` control as the before side (and, when the two latest runs are both controls, pairs the newest control with the newest run of your model), so an improvement is no longer reported as a regression. The `init` success screen no longer shows "[Esc] Cancel". The docs now state that `train --resume` loads the checkpoint weights and runs `iterations` more from a fresh counter. Also pins the transitive `undici` dependency of the AI SDK providers to 7.30.1 or later, which clears four high-severity advisories that were failing the package audit.
