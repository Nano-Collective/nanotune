Fixes found by a release smoke test. llama.cpp installs again: releases are picked from the recent list rather than GitHub's placeholder "latest", and the convert script's `conversion` package is installed with it. GGUF conversion now installs PyTorch when it is missing, so `export` and `benchmark --base` no longer fail with a `torch` import error. A download that fails no longer crashes `train` with a stack dump. `data import` exits 1 when nothing was imported, and `validate --fix` reports unreadable data instead of crashing. Numeric flags to `benchmark` and `chat` are checked before anything runs, so `--ctx-size 4096x` and `--gpu-layers abc` are rejected rather than passed to llama-server. Training loop settings must be positive, which stops `--save-every 0` from failing deep in mlx_lm. Imported records without a context message get the project's. Ctrl+C stops `benchmark` and `export` instead of leaving the work running. A data lock left by a process that crashed on the same machine is reclaimed at once, and one with no readable owner after a minute; a lock held elsewhere is reported after 60 seconds rather than 5 minutes, and a read-only project fails at once. A benchmark whose server dies mid-run leaves the interrupted test out of the score. Fixes #137, #134 and #219.
